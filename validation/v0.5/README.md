## 验收范围与边界

- 默认启动是同步 play()+pause() → 逐镜真实 renderFrame 预热 → 常驻引擎与音频时钟。没有恢复旧分层默认入口。原播放器通过实验页单独回归。
- 默认自动播放策略另测；严格策略使用 document-user-activation-required，去 webdriver 特征、移除测试浏览器默认静音，并先证实无手势 play 被拒。
- 5 秒/25 秒注入在预热完成后继续保持音频响应延迟，确保软件后端也实际经历画面墙钟先行。记录可见载入、真实 analyser 信号、媒体接管、渲染提交时间与媒体时间一致；失败重试另测。
- 实际软件绘制延迟单列 `presentationLagSeconds`，不得将渲染采样时钟一致称为目标设备呈现同步通过。软件主线程可能拖延 20 秒定时器回调，报告同时保留实际 wall/audio 区间和折算 20 秒的音频时钟速率；折算不是恰好 20 秒的实测区间。
- 闪烁算法用可控全局脉冲、持续阶跃、局部亮块及平滑运动验证；实际生成引擎在含硬切的短区间运行双路和切点加密。不是整曲内容验收；作品发布前必须全曲扫描和人工逐项审阅。
- 60 Hz 是时间网格，不是软件后端 60 fps 性能声明。联系表保留正常切镜候选；工具 COMPLETE 不是独立视觉 PASS。
- 目标 GPU、真人扬声器听审、真实歌曲与模型数据、独立作品审美、生产部署均无通过声明。受限输入缺失明确 SKIP；当前实现的自测不代签独立审核。
