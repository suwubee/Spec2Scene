# v0.6 验证边界

运行 `timeout 300s npm run test:v06 -- <临时证据目录>` 会在系统临时目录创建音乐视频项目，启动分配的 39920–39929 回环端口，并保留 phase 连续序列、旧地形前后帧、下载 MP4、Range 响应和 JSON 报告。仓库 `projects/` 不写入作品输出。

回归覆盖：

- 天体相位同种子确定性、倒序可 seek、明暗交界线/地照/视宁度/薄云，单次全屏绘制与三角形预算。
- `terrain` / `surface` 代表帧在默认参数下与 v0.5 基线逐字节相同（其余材质由同一默认 uniforms 与源码契约覆盖）；`slope` 新材质及水面薄雾关闭、月光色和自带地平线选项。
- 播放器缺片的 HEAD 生成中态、就绪下载链接、预热前后 seek、点击/拖动/键盘、2.5 秒唤回、移动触控尺寸、截图路径无控件/无 HEAD。
- 服务端 `video/mp4`、HEAD、Range 206/416 和浏览器下载字节哈希；分享版 CRF 19、16M maxrate 的编码与完整解码候选 QA。
- 渲染停摆守卫只统计非空完整帧，三分钟报警和减半 worker 的续渲建议不执行终止或命令；优先级守卫只调整本次 PID 树中的光栅进程。

本轮软件 Chromium / SwiftShader 只代表库回归信号；目标 GPU 流畅度、真人听审、独立导演审美、真实用户素材授权和生产部署均为 SKIP，不能写成 PASS。黑帧、冻结和闪烁工具的候选仍需人工逐帧判断。失败证据目录不覆盖，修复后使用新轮次。
