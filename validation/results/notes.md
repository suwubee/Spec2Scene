# 验收边界与修复记录

- Node 与浏览器测试验证的是本地共享服务器上的软件环境。模型从官方固定版本下载到生成项目，实际运行本地模型与假摄像头初始化/推理；没有实体摄像头人物精度或实体手机认证。
- 手势、默认自动播放限制、可信点击后的音频调度在浏览器实际验证；服务器环境没有人耳试听条件。
- 视频评测完整执行抽帧、浏览器图像输入、事件指标与联系表，但适配器明确为合成测试，真实获授权人体数据缺失单列 SKIP。
- 初轮验收发现当前无头浏览器需要假摄像头权限 UI 参数；没有修改自动播放策略。模型加载错误增加阶段信息用于开发诊断，产品仍给可理解的恢复提示。
- 初轮截图检查发现笔记本视口操作区溢出；已改为桌面双栏、手机正常文档流，保留声音提示独立空间，最终复验所有指定区域无重叠或越界。
- Python 自检使用现场生成的短合成音频并自动清理，不导入歌曲或语音。歌曲分析、绘图、静音拒绝、两遍响度归一与编码时长均实测。
- rubberband 未安装；可选保音高变速入口有参数与重新分析流程，但本环境没有执行外部 rubberband。基准必需的两个 Python --selftest 已通过；非网络语音自检不证明任何服务的商用许可。
- CLI 派发示例仅验语法与帮助，没有启动额外智能体。四个 SKILL.md 经技能结构验证器检查。
- 源目录仅用于只读参照；没有复制其作品源码、数据、素材、原报告或本地地址。原理与流程改写为通用经验，每条有现象、根因、修复和预防。
