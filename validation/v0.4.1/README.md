# v0.4.1 通用实时播放回归

本轮验证仓库播放器和通过生成器创建的程序化样片，不使用作品音频或来源项目源码。项目由 `scripts/new-project.sh` 在临时仓库的 projects 内生成；当前工作区 projects 不写入。原始报告、音频、截图与失败轮全部留在临时证据目录。

实现入口：[player](../../tracks/music-video/player/README.md)。默认实时模式使用同步媒体解锁、音频主时钟、Worker 构建与渲染、GPU fence、有界帧请求、按镜头顺序空闲 compileAsync、自适应画质与字幕。显式 capture/final 模式固定高画质，无音频或自适应循环。

2026-10-08 实测：Chromium 153.0.8010.12，Linux / ANGLE SwiftShader，2 个软件 shader worker、2 个 CPU、2 个 raster 线程；默认自动播放策略，移除 Playwright 默认静音。普通和 4 倍 CPU 降速各播放 20 秒。下表来自最终完整 npm 回归；同一软件后端的缓存、调度会影响两轮帧时间，不能把它当设备性能排名。

| 条件 | 按钮可用 ms | 点击至解码波形 ms | 墙钟 / 音频推进 s | 自动最终档 | 末尾 4 秒交付 fps / 请求 p90 ms | 首个画面 ms |
|---|---:|---:|---|---|---|---:|
| 普通软件后端 | 73.2 | 52.7 | 20.0002 / 19.9923 | 低，640×360 | 8.0 / 122.4 | 2069.6 |
| 4× CPU 降速 | 111.0 | 9.5 | 20.0011 / 20.0082 | 低，640×360 | 6.5 / 218.1 | 1372.4 |

慢网模拟为 2 Mbps / 100 ms 延迟，额外将音乐请求延后 3 秒、Worker 脚本延后 6 秒。按钮 288.8 ms 可用，显示真实缓冲百分比，点击后登记待播；网络等待计入后，点击至解码信号为 3915.3 ms，可播事件至解码信号为 4.6 ms。网络资源未到达期间没有宣称 ≤1 秒出声。

初始场景单独构建；后续场景在播放约 22 秒时完成顺序空闲预编译。当前软件后端报告 `KHR_parallel_shader_compile=false`，实际执行 compileAsync 回退并保留编译耗时。手动高档完成完整电影场景绘制，准备首个高档画面约 33 秒（含构建和编译）；控件和音频不在这个 Worker 内等待。起播 20 秒内的冷启动和自动换档样本保留在逐帧记录，未从证据中删除。

实测通过范围：

- `npm test`：68/68，0 失败、0 跳过；包括可信点击、未授权自动播放拒绝、解码信号、20 秒时钟、自动/手动档、慢网、弱机、暂停重播、字幕、跨镜头和移动视口。
- `npm run test:browser -- --isolated --offline`：三产线生成/独立测试、拒绝覆盖/路径穿越、页面启动、播放专项、12 帧正反序像素一致、续渲、编码完整解码、音画长度差 0、截图尺寸与布局、打包解压复验；外部请求和页面错误均为 0。
- Python `--selftest`：analyze_song、understand、lyrics/align、lyrics/phrase、gen_voice 共 5 项通过。合成歌对齐不是实际歌曲识别质量认证。
- 视觉查看：实时雪地和站台、完整高档站台、手机布局、固定高档截图，以及远景模型正/侧/背 3 个视角各 3 张连续动作图。远景模型沿用正式骨架与关节约束，几何预算由单测控制；不作为近景脸部、手部或服装验收。
- 卫生检查含仓库规则和仓库外来源禁词表，0 命中；保留所有失败证据后复验。

复跑时可设置 `SCENE_EVIDENCE_DIR` 指定临时证据父目录，`SCENE_PYTHON` 指向已装音乐依赖的 Python；本轮端口限定 `SCENE_TEST_PORT_MIN=39920`、`SCENE_TEST_PORT_MAX=39929`，数值库线程限制为 1。命令均由 timeout 限时，服务 PID 有记录并关闭等待退出。独立播放入口为 `timeout 400s npm run test:playback -- /tmp/scene-player-evidence`。

失败保留与修复：首轮字幕开关显示晚一帧，改为 change 事件立即更新；软件帧率不足，新增可选轻量 HDR 预览、共享关节约束的远景几何与静态合批；自动播放负例原先在自动化 evaluate 调用中触发，受其用户激活语义影响，改为页面 DOMContentLoaded 自发请求；档位切换截图等待 HUD 的实际档位与分辨率刷新，避免周期更新前的旧标签进入证据。

限制：软件低档仍仅约 6–8 fps，**不声明“流畅度已达标”或 30/60 fps**。Windows/Chrome/ANGLE D3D11、真实 GPU、真人扬声器听审和生产环境均 SKIP；缺目标设备与人类听审。解码波形只证明浏览器音频链存在信号。独立“实时可看”与审美关卡仍待审核人亲自确认，不由本回归代签。真实体感数据和模型推理在离线验收中显式 SKIP，无真人识别准确率声明。未部署、未推送。
