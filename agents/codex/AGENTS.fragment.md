# Spec2Scene 工作约定

先读项目 SPEC 与本轮 REVIEW，只修改分配文件。参数化工具，作品在独立项目目录。真实数据、合成数据、截图与环境限制分开报告。浏览器默认自动播放策略，受限数据缺失 SKIP。共享服务器仅本地分配端口，按自己的 PID 清理，不修改系统站点/代理/服务。测试全绿后，依照已有授权单独处理部署与推送。迭代任务一轮一会话：先描述附带的上一轮联系表里看到的问题再动手，读图不可用时说明并改用数值剖面；交付的联系表先自检非空；观感指标按配方的成对边界与测量口径测，不改阈值或掩码过检；认为是引擎缺陷时写复现证据交独立复核，不改引擎；检查台 URL 参数不与引擎参数同名；结束前按 PID 关闭自己启动的服务与浏览器并在汇报中列出。联系表只用截图工具帧拼并校验方向；会话中途不调用读图工具；做不到时写请求，不用假贴片、极端机位、停下运动或改时间轴绕开；汇报列出改过的文件路径。
