# 共享服务器

工作前明确可写目录、只读来源、自己的临时目录、端口段、CPU/内存/磁盘预算。基准验证只监听 127.0.0.1，端口 39920–39939；占用则换空闲端口，不关占用者。

```bash
node tools/serve.mjs --root projects/my-scene --port 39920 > server.log 2>&1 &
scene_pid=$!
# 验证自己的服务后：
kill "$scene_pid"
wait "$scene_pid" || true
```

更推荐测试在 finally 中关闭自己持有的 child process。禁止 killall、按命令行模糊匹配杀进程或取‘最新 Node PID’。日志就绪超时立即清理自己任务，先验证监听地址与 PID，不扫描其他用户文件。

重渲染先低并发测速，保留其他服务余量。只调自己确认的光栅进程优先级，接收帧/磁盘写入/调度进程需及时运行；整棵树降到最低优先级会饿死收帧。确认临时目录是否内存盘，大输出选择用户分配的磁盘空间。

不修改系统站点、代理配置、服务管理器、他人工作目录或缓存。未来任务如明确授权代理变更，仍先备份、nginx -t、重载与回滚准备；此基准创建任务不执行任何系统配置变更。
