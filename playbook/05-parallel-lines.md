# 并行开发线

仅在任务授权并行时使用独立 git worktree，每条线一个职责与目录集合。先提交接口约定：方法、事件、单位、时间源、错误、ready/stop/dispose 与可选能力。共享入口和配置指定唯一集成负责人。

```bash
git worktree add ../scene-input -b feature/input
git worktree add ../scene-ui -b feature/ui
```

测试桩放 tests/，通过依赖注入接入；生产遇到接口缺失显示真实不可用状态。合并顺序通常为底层接口→输入/内容→界面→共享示范→集成。合并热修复时逐条核对旧修复是否保留，不能用整文件一边覆盖另一边。

解决冲突后删除生产桩、校验动态导出形状、跑双方回归及合并版本的完整流程。后台任务保存日志和 PID，阻塞 wait 等待完成，不按进程名字扫描或高频轮询。
