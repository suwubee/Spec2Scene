# 发布封装

发布包只装运行所需代码、授权资源、启动器、许可清单与中文使用说明。排除 node_modules、虚拟环境、缓存、渲染视频/帧、测试/审核、受限数据、密钥和证书私钥。对运行必需的用户音频/模型使用明确 allow-list 或构建清单，不能把源码仓库无选择打包。

生成内部 SHA-256 清单及包的外部 .sha256。在全新临时目录解压，验证所有哈希、相对路径、可执行权限与文件清单，然后运行验证钩子：静态服务器、页面/依赖 0 缺失、短流程、断网已缓存路径。本仓库 make-release 默认排除所有媒体，项目要发获授权媒体时显式配置。

本地化包保持资源相对布局，给 Node/浏览器/FFmpeg 版本要求和失败提示；需要手机摄像头时提供同源 HTTPS 和用户自行配置的证书说明。自签证书在自动化中被忽略验证，不代表实体手机已信任；局域网客户端隔离、网卡选择和权限需真机验证。默认启动器仍只监听本机，不自行开放防火墙。
