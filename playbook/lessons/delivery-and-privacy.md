# 发布、缓存与隐私

每条经验均为匿名化的通用方法。门槛示例须在项目 SPEC 中确认，不能用来伪造历史成绩。

## D01 · CDN 返回旧模块

- **现象**：本地已修复，线上仍执行旧 JS。
- **根因**：入口或同名代码被边缘缓存。
- **修复**：版本化代码目录，HTML no-cache，跨页和动态资源引用随版本更新。
- **预防 / 测试**：部署后比较解码响应体 SHA-256，并用全新与持久浏览器各走一次流程。

## D02 · 模块 MIME 错误

- **现象**：.mjs 被浏览器拒绝或 WASM 流式编译失败。
- **根因**：静态服务器遗漏模块与双扩展名 MIME。
- **修复**：.mjs 为 JavaScript，.wasm.bin 为 application/wasm，.task.bin 为 octet-stream。
- **预防 / 测试**：本地与生产配置同口径，逐路径冒烟，不只检查 200。

## D03 · 长期缓存同名变更

- **现象**：一年缓存使部分用户长期拿不到更新。
- **根因**：修改 immutable 资源内容而不改 URL。
- **修复**：准备阶段比较已发布清单，同名不同摘要拒绝，改文件名。
- **预防 / 测试**：校验 assets/vendor 与代码版本，保留旧资源支持旧页面和回滚。

## D04 · 安全响应头丢失

- **现象**：新增缓存 location 后 HSTS 消失。
- **根因**：nginx add_header 在子层覆盖继承。
- **修复**：在授权配置中明确安全头继承或重复必要头，先备份并 nginx -t。
- **预防 / 测试**：按 HTML/JS/模型/错误响应检查 HSTS/CSP；基准工具不改系统代理。

## D05 · 服务管理器冲突

- **现象**：重启后重复实例、端口争抢，面板状态不可信。
- **根因**：pm2 与面板或其他管理器共同托管。
- **修复**：在授权维护中确定唯一所有者，必要时迁移为 systemd 单实例并保留回滚。
- **预防 / 测试**：核对用户、工作目录、环境、PID 和监听地址，不让部署脚本改服务管理器。

## D06 · 证书自动续期失败

- **现象**：当前 HTTPS 可用，过期后突然不可访问。
- **根因**：新增证书任务或 CDN 缓存/跳转拦截 ACME 验证路径。
- **修复**：沿用现有 SSL 续期机制，核对挑战路径到源站及 CDN 规则。
- **预防 / 测试**：到期监控、授权下演练续期和验证路径；禁止创建竞争续期任务。

## D07 · 本地模型仍外连

- **现象**：资源已本地化，却出现定时统计请求。
- **根因**：库自带遥测与本地资源加载是两条路径。
- **修复**：固定版本，精确补丁禁用发送与定时器，CSP 同源兜底。
- **预防 / 测试**：记录原/补丁哈希及匹配数，等待遥测周期做网络审计，升级复审。

## D08 · 离线缓存不等于秒开

- **现象**：网络零字节，加载页仍长时间显示下载。
- **根因**：缓存免除传输但仍需 WASM 编译、模型创建与首帧推理。
- **修复**：分开缓存命中、下载、解析、编译、就绪；空闲只预取有预算的候选。
- **预防 / 测试**：冷/热阶段对比，不把零 transferSize 一律判为已缓存，测试 SW 更新与离线回退。

## D09 · 发布包带入测试资料

- **现象**：站点部署审核截图、研究文件或受限数据。
- **根因**：递归复制源码目录没有运行清单。
- **修复**：按允许清单构建，排除 tests/review/tools 与缓存、私钥，保留依赖许可。
- **预防 / 测试**：解压后哈希验证与实际启动，扫描运行时引用是否依赖被剔除文件。

## D10 · 离线语音商用误解

- **现象**：已生成的语音被当作完全自有版权内容。
- **根因**：把运行时离线与服务授权混为一谈。
- **修复**：使用可替换引擎，台本/服务/声音/授权/响度/时长入清单。
- **预防 / 测试**：商用发行前核实服务条款；不在仓库分发生成语音。

## D11 · 局域网配对无法使用相机

- **现象**：桌面本地正常，手机权限被拒绝。
- **根因**：手机通过普通 HTTP 地址访问，证书不信任或客户端隔离。
- **修复**：同源 HTTPS、用户配置证书，显示实际局域网入口和隐私说明。
- **预防 / 测试**：实体手机验证证书、网络隔离、权限；自动化忽略证书不算真机通过。
