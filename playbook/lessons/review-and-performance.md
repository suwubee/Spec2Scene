# 审核、测量与协作

每条经验均为匿名化的通用方法。门槛示例须在项目 SPEC 中确认，不能用来伪造历史成绩。

## P01 · 界面灰暗、空洞

- **现象**：功能可用却被评价为阴暗、缺少亲和力。
- **根因**：只看 DOM 与测试，没有视觉目标和可测画面区域。
- **修复**：先建立亮度、色彩、主体占比和字体层级，分离角色与场景光照。
- **预防 / 测试**：按 UI 清单测 ROI 的 L*、对比度、亮暗背景差并人工看图，不照搬参考作品素材。

## P02 · 测试绿而画面错

- **现象**：几何断言通过，动作像挥手，按钮仍覆盖预览。
- **根因**：断言只覆盖目标点或少数元素，遗漏投影、轨迹与声音层。
- **修复**：增加正面/侧面/四分之三及前后六帧，明确 UI 保护区和所有提示层。
- **预防 / 测试**：审核者亲自查看联系表与必要大图，量化与目视双重验收。

## P03 · 测试失败仍上线

- **现象**：测试与发布串联，红色结果没有阻止更新。
- **根因**：shell 分号、后台未 wait、错误码被覆盖或发布版本不同。
- **修复**：拆分测试、准备、激活；证据绑定发布树摘要，失败立即停止。
- **预防 / 测试**：故障注入失败测试，断言不激活；合并后再测试对应版本。

## P04 · 受限数据缺失

- **现象**：换机器后真实回归报文件不存在，或被当成通过。
- **根因**：把本地受限数据视为仓库固定依赖。
- **修复**：独立数据套件，缺数据显式 SKIP 并说明准备和未验证范围。
- **预防 / 测试**：真实文件存在时任何指标失败仍 FAIL；报告保留 SKIP 数及理由。

## P05 · 长会话成本膨胀

- **现象**：相同历史与大图反复读取，返工时间增加。
- **根因**：任务边界模糊，知识留在上下文，频繁轮询与截图。
- **修复**：短任务、文档交接、联系表优先、完成通知；小改直接处理。
- **预防 / 测试**：统计 token 各类别、图像次数和墙钟，避免用缓存命中掩盖总读取量。

## P06 · 并行合并丢行为

- **现象**：界面合并覆盖热修复，测试桩进入产品。
- **根因**：共享文件多负责人，接口未约定，整文件选边。
- **修复**：接口先行与目录归属，依赖顺序合并，逐项对照热修复。
- **预防 / 测试**：合并版本跑双方与集成测试，扫描运行时测试依赖。

## P07 · 未经测量就调参

- **现象**：漏判减少但真实性退化，瓶颈依旧。
- **根因**：把下载、模型初始化、主线程卡顿、检测与判定混为一谈。
- **修复**：记录分阶段时延、输入采集时间、判定原因和冷/热启动。
- **预防 / 测试**：同条件前后对比 p50/p95/max 与首批目标，未复现就明确说明。

## P08 · 共享进程误伤

- **现象**：批量终止命令或优先级调整影响其他服务。
- **根因**：按名字/最新进程定位，未保存启动子进程句柄。
- **修复**：只持有并操作自己的 PID，finally 关闭并等待退出。
- **预防 / 测试**：端口占用换号；限制重任务并发，不读取别人的工作缓存。

## P09 · 研究结论伪精确

- **现象**：推测、搜索摘要与实际查看资料混成事实。
- **根因**：资料层级和证据缺口未记录。
- **修复**：区分实际阅读、间接引述、推断与缺失，冲突并列再说明取舍。
- **预防 / 测试**：报告每个数值来源与可信度，未完成验证不写成已证实。
