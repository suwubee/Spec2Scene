# 反馈回填经验

| 现象 | 根因 | 修复 | 预防 |
|---|---|---|---|
| 把 SVG 叠加误判为主画面不合规 | 忽略主场景与字幕/排版职责 | 检查实际 three.js 场景与捕获合成链 | 主画面三维，叠加层可用 SVG/Canvas；不凭扩展名判定 |
| 整段成熟引擎被当成作品内容删掉 | 未区分通用算法与项目数据 | 保留模块结构、去掉项目数据、参数化输入 | 用接口与来源清单逐模块审核，不直接复制项目源码 |
| 全片只拍远景剪影 | 用避短取代表演设计 | 中远景增加重心、视线、坐姿与动作衔接，无人近物承接细节 | 中景手脸列为不足；远景也要有行动与空间层次 |
| 全曲 DP 穿过器乐导致字幕漂移 | 没有乐句/段落约束，把能量当字义 | 保留人声、静音分句、段落保序、比例行窗，审核批准后锁定 | 行起点相对审核发声点 ±0.3 s，终点不得晚于下一行；比例估计不宣称逐字识别 |
| 长时间无产出或上下文溢出 | 命令无超时、大文件整读、无进展检查 | 每条命令超时，按行取证，60 分钟源文件无变化终止自己的任务并带检查点重启 | 限制重启次数；检查点含约束、已做、失败与下一步；日志增长不算实现进展 |
| 软件截图成功被写成实时通过 | 混淆离线采集和设备预算 | 分开记录采集 PASS、帧时/同步 FAIL、目标 GPU SKIP | 后端、实际画幅/档位、音频领先和短镜头覆盖均需实测 |

本页只保存通用方法，不保存来源作品的名称、歌词、报告或源码。库回归证明接口与确定性；独立关卡仍需审核者实际审阅。
