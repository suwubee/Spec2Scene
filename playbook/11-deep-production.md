# 深做制作法 / Deep production method

这套方法用于需要连续空间、重复镜头和可审阅画面的音乐视频与三维场景。它把“细腻”拆成可以分配、测量和复验的工作，同时把作品内容留在项目输出目录。

## 先收敛场景，再分配工作

一部短片最多保留四个主场景。每个主场景可以有光照、天气、时间或镜头变体，但变体必须复用坐标、材质和资源缓存。超过四个主场景时，先写合并理由和预算变化，再进入制作。

每个主场景有一份 `SET-brief.md`，并由一个智能体或一个明确负责人维护。负责人依次完成四阶段：

1. **空场与光**：只放地面、天空、主光、雾和相机，确认空间尺度、曝光和视线。
2. **英雄画面**：选择一张最能代表场景的画面，完成前景、中景、背景和主道具的层次。
3. **其余预设**：把镜头表中剩余的角度、运动、天气和道具状态接入同一套接口。
4. **收口**：冻结随机种子，清理未使用资源，生成联系表和预算证据，修复后再送美术总监评审。

美术总监按 `AD-review.md` 检查每个阶段。导演的取舍、否决和变更写入 `DIRECTOR-DECISIONS.md`，不要把口头决定藏在代码里。所有场景完成后由集成负责人按 `INTEGRATION.md` 接入镜头表，集成负责人不替场景负责人签署审美结论。

## “细腻”的可目视定义

每个英雄画面必须同时能辨认三层空间：前景遮挡或近物、中景主体、背景空气透视或远景轮廓。主体至少有两层材质信息（基础色/粗糙度与微细变化），并存在可解释的瑕疵，例如边缘磨损、湿度变化、轻微不平整或非重复的排列。空气层由雾、体积光、雨雪或尘埃承担；镜头光学至少明确焦距、光圈和对焦距离。

“细腻”不等于堆放小物。室内英雄帧默认可辨道具数 ≥ 10，室外至少三层可辨构件；项目应另定疏密上限，按叙事优先级分为英雄、辅助和氛围三层；辅助层只在需要时出现。审核者从联系表放大英雄帧，再看一段连续帧，确认细节没有闪烁、重复穿插或随镜头跳变。

## 量化预算与证据

在场景设计书中填写以下预算，并给出测量命令和版本：

| 指标 | 建议预算（在 SPEC 确认） | 记录方式 |
|---|---:|---|
| 看图预算（需逐张记录评价） | ≥ 60 张/场景，英雄帧 ≥ 5 轮 | `docs/evidence/<scene>/hero-*.png` |
| 联系表宽度/帧数 | ≤ 1600 px / ≤ 12 帧，每预设 u=0/.25/.5/.75/1，另看叠化两端 | 联系表元数据 |
| 最终档 draw call | 由设备预算确定，默认 ≤ 180 | `renderer.info.render.calls` |
| 最终档三角形 | 由设备预算确定，默认 ≤ 1.2M | `renderer.info.render.triangles` |
| 常驻场景 | ≤ 4 个 | 场景注册表与运行时日志 |
| 每次换档新增程序 | 记录实测值 | `renderer.info.programs` 计数 |

预算不是自动审美通过条件。软件渲染器的帧时只能作为开发信号；目标 GPU、真人听审和生产浏览器仍需独立记录。

## 并行、接口和收口

只有用户明确授权并行时才使用独立 worktree。接口先行：负责人先提交场景工厂的输入、输出、生命周期、坐标、时间和释放约定，再实现内部细节。测试夹具可以使用合成对象，但桩不能进入运行时产品。

合并前逐项核对场景注册表、共享材质/贴图的所有权、随机种子、dispose 路径和截图命名。集成后重新跑仓库测试与项目测试；失败证据保留，修复后生成新轮次，不覆盖旧证据。

English key points: keep at most four reusable master sets; one owner per set; work in four stages (empty light, hero frame, remaining presets, closeout); define detail through spatial layers, material layers, controlled imperfections, atmosphere and optics; budget hero images, contact sheets, draw calls, triangles and resident sets; use an art-director checklist and an integration contract.
