# 可量化 UI 验收

数值为起始建议，项目 SPEC 应根据观看距离和目标设备确定，不能在失败后暗改。

| 检查项 | 方法与起始门槛 |
|---|---|
| 视口 | 1920×1080、1366×768、390×844、360×780；设置、声音门、错误状态也测 |
| 布局 | 关键按钮/预览/提示/轨道两两无非预期相交；不溢出视口；需滚动的文档与主流程区分 |
| 对齐 | 标签与控件中心差 ≤6 px；触控目标 ≥48 px，远距离手势区域更大 |
| 可读性 | 正文对比度 ≥4.5:1，大字 ≥3:1；远距离提示建议 ≥24 px，手机 ≥16 px |
| 亮度 | 指定 ROI 的 L* 目标区间；角色在亮/暗背景平均亮度差 <15%；记录原始测量 |
| 主角 | 演示主体足够大；护脸时眼嘴可见；转台、多视角动作、连续轨迹逐格看 |
| 音符 | 球径等于判定圈内径，外径 ≤1.15 倍；中心距 ≥1.1 倍球径；不以进阶难度缩小球 |
| 层级 | 装饰不压轨道，骨架不压目标，判定字不遮下一目标，声音横幅不遮预览 |
| 声音 | 独立显示静音与浏览器锁定；无点击手势开始可见提示，点击后实际出声 |
| 内容 | 字体子集不缺字，无装饰英文噪声；截图数据自洽，模拟成绩不进入真实活动记录 |

自动检查只能验证指定元素/状态，必须实际查看截图与听音；记录自动检查覆盖的 selector 与未覆盖区域。
