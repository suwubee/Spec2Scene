# 体感游戏 QA

- 感知层级、坐姿/单手/近景/全身，推荐与直接开始。
- InputSource 契约、时间单位、镜像坐标、模型许可/版本/遥测审计。
- 检测→期望匹配→判定分档，延迟补偿、no_motion 等原因日志。
- 站位有限重试与风险提示；保持/悬停/暂停/键盘；默认浏览器声音解锁。
- 音乐网格/变速/谱面间距/音符圈尺寸；语音时长/优先级/覆盖表。
- 统一示范组件、多视角动作、声音优先、个人舒适范围与安全退出。
- 真实视频/图片/头姿回归，开发与留出集，缺数据 SKIP 边界。
- PWA、配对骨骼协议、离线/慢网/本地包与真机复验。

每条标记 PASS / FAIL / SKIP / 未执行，附命令、退出码、输入摘要、浏览器/后端、截图路径与人工结论。规格门槛不得在失败后降低。通用 UI 检查见 [清单](../../templates/ui-acceptance-checklist.md)，测试方法见 [playbook](../../playbook/06-testing.md)。
