# 体感游戏产线

按脸、手、上半身、全身定义 minTier/bestTier，用现有模型优先推荐能玩的动作。近景不强制髋部，单手可开始，距离和站位质量给提示而不无限拦截；真实安全风险允许退出或无评分跟练。

统一 InputSource 的 start/sample/stop 生命周期，采集时间以秒给上层，模型 detectForVideo 使用毫秒；区分解剖学左右与镜像显示。MediaPipe 固定版本本地加载，显式 WasmFileset 与 import.meta.url；模型 .bin 从官方按需下载，记录许可与哈希，遥测和 CSP 单独审计。

检测器负责运动事件，期望匹配器负责当前目标，判定层集中配置宽容档位、延迟补偿与诊断日志。真实视频固定抽帧→模型→滤波→事件→一对一指标→联系表；手部补真实图片类别与距离曲线，头部补真实姿态误差。SimPose 是流程测试接口，不能替代真人精度证明。

交互包含保持确认、悬停点击、举手暂停与键盘备用；音频必须在本页可信点击/按键中解锁，手势不属于用户激活。开始/加载/站位/错误/结算都测无鼠标路径；声音门放正常布局，自动化保留默认自动播放策略。

音乐使用实际发布编码的网格和变速重分析，音符与判定圈共用几何，难度不缩小音符。语音离线生成并测实际时长，完整→短句→组合名保证覆盖，开场串行，转头/下蹲时声音优先。统一大尺寸、镜像、慢速的示范→轨迹→跟做组件，动作须多视角及序列审核。

PWA 只缓存已用或预算内预取资源；缓存与初始化分开。手机同源 HTTPS 配对只传骨骼/事件，短期配对码、schema/频率/Origin 限制、断线暂停。慢网有限重试、Range 续传、低码率或节拍器回退。本地化包经过独立解压启动，真实手机许可/证书仍需真机验证。

开始：`scripts/new-project.sh motion-games <name>`。详见 [规格](SPEC.md)、[QA](QA.md)、[经验](lessons.md)、[通用工具](../../tools/README.md)。
