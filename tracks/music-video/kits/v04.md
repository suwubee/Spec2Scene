# v0.4 通用构件

全部参数使用项目坐标、种子和绝对时间；无下载或作品内容。`kits/bench/v04.html?mode=cloud` 可切换 `water / rock / mountain / sky / fog / shaft / character / subtitle`。用 `timeout 1200s node scripts/validate-v04.mjs <临时证据目录>` 渲染联系表和正侧动作序列，同帧二次与逆序逐字节比较。默认自动播放策略、单浏览器两线程、任务端口段由 `SCENE_TEST_PORT_MAX` 收紧。

| 能力 | 接口 | 边界 |
|---|---|---|
| 低空珍珠白月盘 | `createSky(ctx,{moonTint:[1,1,1],lunarDiscNeutrality:1})`；world 同名通道可覆盖 | 0 保留物理消光，1 等亮度中和；月盘/晕共享，云仍有独立 neutrality |
| 逐帧月相 | `world.moonPhaseAngle`，0°满月、180°新月 | 世界缺省时回退创建参数；缓存键包括月相与中和量 |
| 云海 | `createCloudSea({bounds,steps:40,shadowSteps:5,density,scale,seed,silver})`，`update(t,world)` | 有限盒体积、光线步进、自阴影、前向银边；无历史缓存。透明几何与嵌入云内的不透明物件交界仍需审图 |
| 小水面 | `createSmallWater({kind:'basin'|'jar'|'puddle',radius,height,position,resolution,puddles})` | 真实平面场景反射；同一 puddle 组共用一张 RT；不同高度分开，代价须测量 |
| 长焦远山 | `telephotoMaxStep({distance,focal,sensorWidth,width,pixels})`；`createMountainLOD({height,bounds,maxSegments}).update(camera,{width,t})` | 焦距驱动细分，`budgetLimited` 标记预算不足；切档可能跳变，离线按最紧镜头预建或提高上限 |
| 连续地形远端细分 | `sampleAxis({...axis,maxStep})` | 抑制长三角形；超过轴/顶点预算报错 |
| 外部谷雾地形 | `createAtmosphere(ctx,{sky,terrain:{heightAt,waterMask,bounds,resolution,skylineAt}})` | 静态高度/水域纹理，雾相对本地地面；可提供地平线函数，默认采样同一高度场；时变地形需重建 |
| 室内月光 | `createInteriorMoonlight({window,floor,wall,intensity,bounce,diffuse,range})` | 有动机的直接光、地面反弹与墙面漫射近似；不声称 GI |
| 岩石 | `createRock({radius,detail:5,seed,scale,color,roughness})` | 多频形变、共享顶点法线、程序材质细节；超近景仍需专门资产 |

后期合并顺序为 `world.post → 全局 postOverride → shot.post/shot.grade → seek(t,{post})`，`world.exposureBias` 仍作为最终 EV 偏置叠加。`shot.post` 可为 `(tLocal,state)=>({...})` 曲线；JSON 镜头表使用静态参数。分镜曝光/白平衡不会再被全局默认值压掉。调用方 seek 的显式 override 仍有最高优先级。

光柱在实际 draw 前刷新 shader uniforms，使 FX 层绑定本帧深度状态。不能通过预渲一遍隐藏确定性问题；回归比较第一次、第二次与倒序像素。

人物 composition 提供保守屏幕包围盒（归一化左上原点）。字幕默认上移或换边，输出 unresolved 时必须调整排版；包围盒不证明物体的真实可见像素。三维反射、云海、谷雾均需检查层次、接缝和资源成本，软件截图不代替真机实时预算。
