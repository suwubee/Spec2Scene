# 音乐视频产线

从用户提供且获授权的音频开始。先确认纯代码/图像生成/转录限制、歌词、署名、画幅、母版与分享版等交付。自动分析给节拍、小节、能量与段落候选，导演结合聆听、旋律和乐器对话决定同步点。

按音乐事件写分镜：开始/结束、场景、镜头运动、转场、焦点、字幕和成本；所有场景读同一 world.at(t)，统一坐标、光照、曝光与母题参数。动画是时间、种子与参数的纯函数，页面暴露 `window.__scene={ready,canvas,seek(t)}`，seek 支持乱序和转场范围。

先小画面稀疏预览与联系表，审核所有镜头、字幕和署名后再 final。正式渲染前记录源码/数据摘要作为 identity、浏览器和后端；帧逐个原子写入，固定 fps，不靠墙钟。只在相同配置续渲，缺帧拒绝编码，预留服务器 CPU 和磁盘。

使用 tools/render-frames.mjs → tools/encode.sh → tools/qa.mjs；重新开浏览器逆序渲染比原始像素。黑场、冻结、色带和音画长度是候选检查，转场/闪光须逐格审核；母版与分享版分别 QA。导出源码、运行与本地渲染指南、输入授权、联系表和质检报告，作品不回填基准仓库。

开始：`scripts/new-project.sh music-video <name>`。详见 [规格](SPEC.md)、[QA](QA.md)、[经验](lessons.md)、[通用工具](../../tools/README.md)。
