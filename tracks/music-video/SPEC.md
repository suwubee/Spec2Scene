# 音乐视频项目规格

先填写本次用户原话、目标、硬性约束、文件归属、接口与可量化验收。素材与数据只在当前项目保存。

## 产线必填章节

- 音频许可、是否允许转录、歌词来源与音乐理解方法。
- 音乐结构与同步点：来源时间、置信度、人工聆听意见。
- 分镜表：镜头起止/场景/转场/世界状态/字幕/预算。
- seek(t)、seed、坐标、曝光、子帧与字体就绪契约。
- 预览冻结清单；正式帧范围/fps/后端/identity/磁盘预算。
- 确定性、转场、冻结、黑场、色带、音画差与发布编码验收。

## v0.2 导演与三维必填项

主画面使用 three.js 三维；SVG/Canvas 可用于叠加层与排版。

- 意境书：一句话母题、全曲情绪温度、时代/空间/季节/天气/时段、色彩脚本、主光方向/色温/光比、3–5 母题、不做什么。
- 意象转译表：关键词 / 要避开的字面画法 / 情绪内核 / 替代意象 / 构图与镜头 / 光 / 前后呼应。孤独大景人物面积 <3%、负空间 >60%，以最终截图测量。
- 分镜：时间码、音乐事件、乐句情绪、景别、14–135mm 焦段、机位与运动起止、focus/fstop、光、表演、转场、呼应、风险；使用完整镜头 JSON 驱动。
- 三维纵深、三层空间、半浮点 HDR、ACES/AgX、bloom、物理参数景深、空气雾/光、字幕安全区。
- 角色：体型、头身比、衣服、关节限位、IK、动作、接触目标、自动人体检查、转台和动作序列。
- 性能：目标设备与后端、分辨率、DPR、帧时间 p50/p95 预算、显存和降级次序；软件图形结果单列。
- 独立 G1/G2/G3：审核人、各关证据、被审版本、结论、复验；前一关未 PASS，不进入下一关。
