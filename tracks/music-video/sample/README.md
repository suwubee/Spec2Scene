# 60 秒虚构样片

无真实歌曲、歌词或署名；静音时间轴，所有对象程序化。第一段为雪夜旷野（0–30s），同一个升起长镜头由脚印读出距离，再让人物被空间吞没。第二段为雨夜站台（30–60s），空座与余光回应前段，使用叠化、硬切、焦点转移和远景背影。

母题：痕迹、缺席的位置、残光。冷蓝旷野与小面积暖灯的青灰站台组成色彩脚本。分镜与意象论证见 ../directing/，可执行数据为 shots.json。前景脚印/近雪、中景人、远山为雪夜三层；近雨/柱、中景人和空座、远方灯与建筑为站台三层。

起步代码是能力示范。用户作品必须从意境书重新设计，不能只换音频或把歌词逐行塞入镜头。示范截图只作实现者自检证据，G1–G3 独立审核状态留在验证报告，未代签。

离线验收使用 1920×1080 画布、约 2.39:1 有效画面和完整后期。雪地在脚印区域加密高度场，山体按坡度分配积雪；站台使用向下的实际聚光灯、独立雨光束、低密度薄雾及铺装上的平面反射水膜。雨光仍采用解析点光近似，水膜不是流体模拟。现有角色只用远景和背影，角色结构由独立产线验收。
