# 审美底线 / Quality bar

主画面一律 three.js 三维；SVG/Canvas 可用于叠加层与排版。只显示一张“像三维”的二维画不算满足。验收应移动或 seek 相机，查看遮挡、透视、视差、真实深度缓冲和光线层次。

| 检查项 | 可量化门槛 | 必须目视确认 |
|---|---|---|
| 空间 | 每镜至少前/中/后三层；标注对象与距离 | 空气透视与深度层次清楚，没有平涂纸片感 |
| 意象 | 全片 3–5 母题；大景人物面积 <3%，负空间 >60% | 静音去字幕仍能感到情绪；意象有前后关系 |
| 镜头 | 所有镜头有焦段、起止机位、对焦距离、光圈 | 移动有落点，长镜头不中断，切换由乐句决定 |
| 光照 | 半浮点 HDR + ACES/AgX；标注主光方向与光比 | 灯具有动机，亮部不大片烧白，暗部仍有材质信息 |
| 空气 | 体积光或雾；至少一个镜头能看到前后衰减 | 光柱边界柔和，雨雪处在空间里，不能像贴在屏幕上 |
| 景深 | 焦段/光圈/焦距可复查；拉焦前中后证据 | 焦点确实引导注意，边缘无明显模糊漏色 |
| 色彩 | 对照每段色彩脚本；大面积高饱和色应有理由 | 冷暖关系一致，跨镜曝光连续；不一键滤镜掩盖平光 |
| 角色 | 人体检查全绿；八向转台 + 动作序列 | 写实比例，重心合理，肘膝不反折、手脚不穿插 |
| 字幕 | 默认安全区左右 ≥8%、底 ≥8%；最多两行；1080p 字高 ≥32px | 字重与对比可读，不能遮住意象落点；字体授权与加载已验证 |
| 连续性 | 整曲联系表、各段关键帧、≥3 段连续帧 | 非刻意冻结、粒子跳变、跨轴、焦点抽动均打回 |
| 性能 | 记录分辨率/后端/帧时间 p50/p95；项目预先设硬件预算 | 降级先减粒子与分辨率，保留构图和光；软件后端单列 |

每项 0=不达标，1=功能存在但需要改进，2=达到意境书；任一项 0 或人体 FAIL，G3 不通过。审美结论由独立审核者签字，截图数量、平均亮度和自动测试不能代替审美判断。成片的实际硬件实时预算由项目 SPEC 预先冻结，不能看到结果后再放宽。

常见“丑”的原因与修复：平光→明确主光和暗面；无景深→先拉开空间再调光圈；等距排列→用尺度与聚散变化；过饱和→缩小强调色面积；镜头不动或乱动→为乐句写观看目标；逐句切换→把多个语义组织成一段空间体验；脚印像灯带→降低发光、保留凹陷与方向；人物像卡通→先改头身比、轮廓与材质，再加面部细节。

English: Measure the composition, but judge the image. A technically valid frame can still fail the mood, lighting or performance review.

当前关卡依次 G1（意境/分镜/样张）→G1b（新引擎重渲）→G2G3（全曲/表演/字幕）→FINAL。库自测不代签独立审美或真实听审；中景人物手脸继续列为不足。
