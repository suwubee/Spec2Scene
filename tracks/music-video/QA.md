# 音乐视频 QA

- 音频许可、是否允许转录、歌词来源与音乐理解方法。
- 音乐结构与同步点：来源时间、置信度、人工聆听意见。
- 分镜表：镜头起止/场景/转场/世界状态/字幕/预算。
- seek(t)、seed、坐标、曝光、子帧与字体就绪契约。
- 预览冻结清单；正式帧范围/fps/后端/identity/磁盘预算。
- 确定性、转场、冻结、黑场、色带、音画差与发布编码验收。

每条标记 PASS / FAIL / SKIP / 未执行，附命令、退出码、输入摘要、浏览器/后端、截图路径与人工结论。规格门槛不得在失败后降低。通用 UI 检查见 [清单](../../templates/ui-acceptance-checklist.md)，测试方法见 [playbook](../../playbook/06-testing.md)。

## 强制独立关卡

| 关卡 | 输入 | 必须复验 |
|---|---|---|
| G1 | 意境书、意象转译表、色彩脚本、全曲分镜、每段气氛样张 | 静音去字幕的情绪；是否逐句图解；母题呼应；长镜头/剪辑是否服从乐句 |
| G2 | 人体 JSON、八方向转台、关键动作序列 | 肘膝铰链方向、肩髋颈腕、骨长、手与躯干、落脚与滑步、镜像、重心和服装遮挡 |
| G3 | 全曲联系表、每段关键帧、≥3 连续序列、性能、复渲 | 三层空间、HDR/光照、体积雾光、景深/焦点、色彩、字幕、相机与表演连续性 |

使用 templates/REVIEW-music-video.md；独立人员/会话逐图签结论。实现者自审不算审核；FAIL 不得进入下一关。目标设备、真实音乐和授权输入缺失时写明 SKIP 原因。程序化静音样片只证明工具能力，不证明真实作品或生产验收。

## 实时可看

审核人在默认实时页亲自点播放；记录按钮可用 ≤1 秒、预热与音乐均就绪至首声 ≤1 秒（预热/网络等待单列）、20 秒音频推进 19.6–20.4 秒、实际交付 fps、冷启动/稳定帧 p90、固定尺寸/画质（实验选项另记换档）、慢网与弱机各一次。检查暂停重播、字幕开关、缓冲进度；默认自动播放策略且不静音。截图模式显式固定高画质，不代替实时验收；解码波形、真人听审和目标 GPU 分别记录。详见 [默认播放器](realtime/README.md)。

音乐视频发布前必查：`npm run check:flicker`（新轮次输出目录），保存 rows.json、flags.txt、联系表及连续帧。覆盖 24 Hz seek、60 Hz 实时策略与硬切 ±1/4.5/25 ms；逐项解释正常切镜候选，修复其他异常并复验。命令完成或零候选均不代签独立视觉验收。核对世界观、禁用清单和 AD 评审 1 结论。

## 画面自动质检 picture-qa（强制）

每一版每镜代表帧先过 [picture-qa](../../tools/picture-qa/README.md)：`npm run qa:picture -- --dir <看图目录>`，全部 PASS 才送导演初审或独立审核；修复轮必须 `--compare <上一轮> --claim <检查项>`，⑥ 证明问题区域确实变化。它是纯像素统计，不依赖任何模型，所有模型都能运行；检查 ① 条纹/各向异性 ② 外缘光晕 ③ 平涂 ④ 亮度分布 ⑤ 积云团 ⑦ 暖色占比 ⑥ 与上一版差异。逐镜配置 `docs/picture-qa.shots.json` 由 `npm test` 校验，豁免必须有理由。报告进入 GATE/REVIEW 证据；PASS 不代签审美。规则与分工见[画面关卡](../../playbook/14-picture-gate.md)。构件检查台按本构件掩码测：`--mask <区域> [--exclude <邻件>] --erode 2`（`masks.json` 与帧同目录，排除写 `_why`）；观感指标在配置层 `surface` 写成对上下限（单侧须 `oneSided` 理由），人物加 `--silhouette <人物掩码.png>` 判结构；颗粒敏感指标用 1920 宽并锁颗粒，掠射采样贴表面。每轮交付附自检非空的联系表，迭代日志记“约束改动 → 可见结果”，每件最多三轮。

## 设计深度、引擎能力与相机（强制）

派发实现前 `npm run qa:brief` PASS（每份 SET 组件表八列写满、NEW-HARD 八项配方、逐镜物料清单、设计者手写字节下限）；每轮代码 `npm run qa:reimplement` 0 条；有相机运动时在服务运行中 `npm run qa:camera` 每镜 PASS（p95 ≤ 1.5 px、rms ≤ 1.5 px、峰值 ≤ 4 px，1920 宽）。英雄镜头的 AD/G3 审核附标杆帧并排对照表；用户否决已通过的内容时写审核误判记录。规则见[深做制作法](../../playbook/11-deep-production.md)与[审核章节](../../playbook/03-review.md)。
