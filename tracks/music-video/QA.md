# 音乐视频 QA

- 音频许可、是否允许转录、歌词来源与音乐理解方法。
- 音乐结构与同步点：来源时间、置信度、人工聆听意见。
- 分镜表：镜头起止/场景/转场/世界状态/字幕/预算。
- seek(t)、seed、坐标、曝光、子帧与字体就绪契约。
- 预览冻结清单；正式帧范围/fps/后端/identity/磁盘预算。
- 确定性、转场、冻结、黑场、色带、音画差与发布编码验收。

每条标记 PASS / FAIL / SKIP / 未执行，附命令、退出码、输入摘要、浏览器/后端、截图路径与人工结论。规格门槛不得在失败后降低。通用 UI 检查见 [清单](../../templates/ui-acceptance-checklist.md)，测试方法见 [playbook](../../playbook/06-testing.md)。
