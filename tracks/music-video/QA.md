# 音乐视频 QA

- 音频许可、是否允许转录、歌词来源与音乐理解方法。
- 音乐结构与同步点：来源时间、置信度、人工聆听意见。
- 分镜表：镜头起止/场景/转场/世界状态/字幕/预算。
- seek(t)、seed、坐标、曝光、子帧与字体就绪契约。
- 预览冻结清单；正式帧范围/fps/后端/identity/磁盘预算。
- 确定性、转场、冻结、黑场、色带、音画差与发布编码验收。

每条标记 PASS / FAIL / SKIP / 未执行，附命令、退出码、输入摘要、浏览器/后端、截图路径与人工结论。规格门槛不得在失败后降低。通用 UI 检查见 [清单](../../templates/ui-acceptance-checklist.md)，测试方法见 [playbook](../../playbook/06-testing.md)。

## 强制独立关卡

| 关卡 | 输入 | 必须复验 |
|---|---|---|
| G1 | 意境书、意象转译表、色彩脚本、全曲分镜、每段气氛样张 | 静音去字幕的情绪；是否逐句图解；母题呼应；长镜头/剪辑是否服从乐句 |
| G2 | 人体 JSON、八方向转台、关键动作序列 | 肘膝铰链方向、肩髋颈腕、骨长、手与躯干、落脚与滑步、镜像、重心和服装遮挡 |
| G3 | 全曲联系表、每段关键帧、≥3 连续序列、性能、复渲 | 三层空间、HDR/光照、体积雾光、景深/焦点、色彩、字幕、相机与表演连续性 |

使用 templates/REVIEW-music-video.md；独立人员/会话逐图签结论。实现者自审不算审核；FAIL 不得进入下一关。目标设备、真实音乐和授权输入缺失时写明 SKIP 原因。程序化静音样片只证明工具能力，不证明真实作品或生产验收。
