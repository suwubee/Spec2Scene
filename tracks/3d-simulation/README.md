# 三维模拟产线

先整理获授权地图、影像描绘与资料，登记获取日期、许可、单位、投影、原点、方向和误差。位置/轮廓、形制/高度、植被/石形分别标可信度；地图记录不自动等于现场实测。影像只作有授权的研究参照，不随仓库附带。

从外环、内环、线、桥、开放屋顶、门等语义建立地形水面和构件；程序化建筑/植被/岩石使用参数化锚点、种子和包围盒，受道路/水域遮罩约束。使用实例化、合批、LOD 与材质复用，生成对象保留 provenance，提供可逆来源颜色视图。

漫游包括鸟瞰、步行、地标定位、标签去重、小地图和质量设置。游线来自连通道路图，只通过真实门连接内外，桥和台阶减速，按弧长移动；平滑不得穿墙、越水，记录不可达点、路线长度与步行时间。

移动端在构建前减少内容数量和纹理，低内存档不仅降低 DPR。启动标记在 ready 清除，失败后下一次自动降级；contextlost 给可恢复入口。实测对象数、JS 峰值、draw calls、帧时分位数。静态构建后从独立目录启动并检查数据、模块及触控路径。

起步页只是原创程序化透视线框和来源切换，验证工具/数据契约；项目需自行导入真实数据和扩展渲染器。

开始：`scripts/new-project.sh 3d-simulation <name>`。详见 [规格](SPEC.md)、[QA](QA.md)、[经验](lessons.md)、[通用工具](../../tools/README.md)。
