# 三维模拟经验

每条经验均为匿名化的通用方法。门槛示例须在项目 SPEC 中确认，不能用来伪造历史成绩。

## S01 · 真实地图被艺术化改位

- **现象**：建筑看似漂亮但位置、方向、形状不符。
- **根因**：先画场景后补数据，推测掩盖缺口。
- **修复**：先统一坐标原点、米制单位与轴向，位置/轮廓来自获授权数据。
- **预防 / 测试**：顶视叠加和地标误差验收；缺口标待核验，不捏造真实对象。

## S02 · 测绘与推定混淆

- **现象**：用户无法判断什么是真实、什么是生成。
- **根因**：只在说明中笼统写有地图来源。
- **修复**：按对象或属性记录地图记录、影像描绘、资料推定、程序生成、估算及可信度。
- **预防 / 测试**：可逆来源材质视图+图例+计数，不把 OSM 自动等同现场实测。

## S03 · 岛洞、水面与走廊错误

- **现象**：水淹岛屿、走廊被实心建筑填满。
- **根因**：忽略 multipolygon 的 inner rings 和 roof/bridge/footway 语义。
- **修复**：解析外环内环、开放路径与桥层级，构件按数据语义建立。
- **预防 / 测试**：环方向、拓扑、面积、孔洞和桥路连通单测及顶视审核。

## S04 · 卫星描绘整体错位

- **现象**：树冠或建筑相对道路偏移。
- **根因**：影像坐标、拍摄时间、投影或基准与地图不同。
- **修复**：用稳定控制点配准，标影像日期、偏移与误差，遮挡处保留不确定性。
- **预防 / 测试**：叠加比对道路交点、重复轮廓与置信度；不把影像纹理带入作品。

## S05 · 程序对象侵入道路

- **现象**：植被和石块遮挡可走区域。
- **根因**：随机分布未考虑水、路、门与建筑占地。
- **修复**：按真实遮罩与距离场排除道路、水域和门洞，种子确定性。
- **预防 / 测试**：检查每个生成实例的约束；多高度视角与关键游线走查。

## S06 · 构件接口拼不齐

- **现象**：墙、屋顶、地基出现缝隙或尺寸错配。
- **根因**：模块单位、基准高度、朝向、LOD 契约不一致。
- **修复**：参数化建筑、地形、植被各自定义锚点、包围盒、材质与 dispose。
- **预防 / 测试**：部件图鉴与集成典型截面，LOD 切换连续、实例/材质可复用。

## S07 · 游线跳跃或穿墙

- **现象**：镜头直接飞到景点，路径看起来不像真实游览。
- **根因**：只有地标列表，没有道路图和合法入口。
- **修复**：构建步道/走廊/桥/台阶图，只在真实门连接内外，寻路再按弧长行走。
- **预防 / 测试**：报告连通分量、不可达点、长度与时间；平滑不得离开可走带。

## S08 · 镜头看墙和标签拥挤

- **现象**：停留视角朝向近墙，小屏标签覆盖。
- **根因**：只验证轨迹点，不检查视线和屏幕投影。
- **修复**：按焦点与可见性设计停留，标签按距离和优先级去重，小地图朝北。
- **预防 / 测试**：轨迹序列截图、墙距、碰撞、标签包围盒和手机触控测试。

## S09 · 手机加载崩溃

- **现象**：桌面正常，手机构建阶段被浏览器杀掉。
- **根因**：只降 DPR，仍创建全部几何/树木/纹理与周边。
- **修复**：在构建前选择省内存内容档，合批/实例化/LOD，减少高成本对象。
- **预防 / 测试**：报告 JS 峰值和对象预算，低内存设备默认低档，真机复验。

## S10 · 崩溃后无限重开

- **现象**：同一大场景每次打开都崩溃。
- **根因**：没有上次启动标记和 contextlost 恢复。
- **修复**：启动写 boot 标记，ready 后清除；检测未完成启动自动降级，contextlost 提供重载。
- **预防 / 测试**：注入失败与存储不可用，确保低档可进入且降级原因可见。

## S11 · 来源视图损坏原材质

- **现象**：切换后反射、透明度或共享材质永久改变。
- **根因**：直接修改共享材质且丢失原状态。
- **修复**：保存原材质引用，可逆替换，不重新生成场景。
- **预防 / 测试**：多次切换后截图/资源数一致，dispose 不释放仍被使用资源。

## S12 · 静态发布遗漏数据

- **现象**：开发环境可读文件，发布构建后 404。
- **根因**：相对路径依赖源码目录，数据没入清单。
- **修复**：统一 import.meta.url 与构建复制契约，编译后独立目录验证。
- **预防 / 测试**：不需要运行时构建服务；解压实际打开，检查所有数据和模块请求。

## S13 · 影像时间、视差与分类推测

- **现象**：屋顶、地面、树冠的配准偏移不同，季节变化导致落叶树漏检，自动屋顶轮廓误覆盖道路。
- **根因**：把拼接影像视为单次拍摄，把屋顶视差当作地面偏移，把颜色/纹理启发式当作树种或建筑层数事实。
- **修复**：按拍摄分区和高度层分别配准，记录原生分辨率、日期与误差；遮罩排除道路水体和已知对象；分割成规则单元明确标为程序推定。
- **预防 / 测试**：控制点叠加、区域留出验证、道路误报与重复覆盖统计；树冠中心不直接称为树干位置，推断层数/种类单独标低可信度，影像本身不再分发。
