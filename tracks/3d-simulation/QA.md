# 三维模拟 QA

- 数据许可表与获取日期，坐标/单位/轴向/高程基准。
- 来源分级：地图记录、影像描绘、资料推定、程序生成、估算。
- 几何约定：外环/内环/走廊/桥/道路/门，锚点与误差门槛。
- 可逆 provenance 材质视图、图例和计数。
- 鸟瞰/步行/地标/小地图/路线拓扑/速度/视线与连续性。
- 手机内容预算、低内存策略、启动失败与 contextlost 恢复。
- 独立静态编译、数据引用、视口、顶视叠加和性能证据。

每条标记 PASS / FAIL / SKIP / 未执行，附命令、退出码、输入摘要、浏览器/后端、截图路径与人工结论。规格门槛不得在失败后降低。通用 UI 检查见 [清单](../../templates/ui-acceptance-checklist.md)，测试方法见 [playbook](../../playbook/06-testing.md)。
